# 🧮 Calculator

## 📌 About the Project

This is a simple and user-friendly calculator web application developed using HTML, CSS, and JavaScript. It performs basic mathematical operations quickly and easily.

## ✨ Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear button to reset calculations
* Simple and user-friendly interface
* Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your web browser.
4. Start using the calculator.

## 🎯 Purpose

The purpose of this project is to practice HTML, CSS, and JavaScript and improve my web development skills.
